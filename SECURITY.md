# Security Policy

## Supported versions

Security fixes go into the latest release. Upgrade to the newest `tainersh/tainer` tag to receive them.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report it privately through [GitHub security advisories](https://github.com/wiflow/Tainer/security/advisories/new). Include the Tainer version, what an attacker can do, and the steps to reproduce it.

## What to expect

- Within 3 business days: a reply confirming the report was received.
- Within 10 business days: an assessment of whether it is a vulnerability and how severe it is.
- Within 90 days of the report: a fixed release for confirmed issues, sooner for critical ones. If a fix needs longer, you get an update with the reason and a new date.

Once a fix is released, the advisory is published with credit to the reporter unless you prefer to stay anonymous. Please keep the details private until then.
